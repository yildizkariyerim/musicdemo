# 🎧 Music Streaming User Analysis

## 📌 Proje Hakkında

Bu proje, bir müzik streaming platformuna ait kullanıcı verileri üzerinde gerçekleştirilen uçtan uca veri analizi çalışmasını içermektedir.

Proje kapsamında Excel, SQL ve Python kullanılarak kullanıcı davranışları incelenmiş, kullanıcı segmentleri karşılaştırılmış ve churn (müşteri kaybı) davranışına yönelik analizler gerçekleştirilmiştir.

---

## 🎯 Proje Amaçları

- Kullanıcı davranışlarını analiz etmek
- Free ve Premium kullanıcıları karşılaştırmak
- Churn davranışını incelemek
- Kullanıcı etkileşim metriklerini değerlendirmek
- Veri kalitesi kontrolleri gerçekleştirmek
- İş kararlarını destekleyebilecek içgörüler üretmek

---

## 🗂️ Veri Seti

Veri seti, bir müzik streaming platformundaki kullanıcı aktivitelerini temsil etmektedir.

| Kolon | Açıklama |
|---------|---------|
| user_id | Kullanıcı kimliği |
| age | Kullanıcı yaşı |
| country | Kullanıcının ülkesi |
| subscription_type | Abonelik tipi |
| device | Kullanılan cihaz |
| daily_minutes | Günlük dinleme süresi |
| favorite_genre | Favori müzik türü |
| skip_rate | Şarkı geçme oranı |
| ads_clicked | Reklam tıklama durumu |
| churned | Kullanıcının platformu bırakma durumu |
